# WCAG 2.2 AA contrast audit of Dani's v1 token set — Alex — 2026-05-23

## Summary

Independently calculated contrast ratios for all 18 color pairs Dani listed in DESIGN.md v1, using the WCAG sRGB relative-luminance formula. **16/18 pass; 2 FAIL.** Both failures are the `borderStrong` token (used for form-input borders) in both light and dark modes. Proposed fixes attached and applied.

## Methodology

For each pair `(foreground, background)`:

1. Convert hex → sRGB → linear RGB via the WCAG sRGB-to-linear formula.
2. Compute relative luminance L = 0.2126·R + 0.7152·G + 0.0722·B.
3. Contrast = (L_lighter + 0.05) / (L_darker + 0.05).
4. Compare against WCAG 2.2 thresholds:
   - **AAA**: ≥7:1 (regular text), ≥4.5:1 (large text)
   - **AA**: ≥4.5:1 (regular text), ≥3:1 (large text + non-text UI per 1.4.11)
   - **FAIL**: <3:1 for any visible element
