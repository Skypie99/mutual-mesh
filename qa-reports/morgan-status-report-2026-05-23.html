04  What unblocks Cycle 2

The schema is a file. Applying it (Sky-only, in the Supabase dashboard) is the gate. Summary of the 8 steps from the Cycle 1 briefing:

  1. Enable extensions: pgcrypto, pg_cron.
  2. Run supabase/schema.sql in the SQL editor; verify the 6 tables exist.
  3. Run supabase/realtime.sql; confirm users + resources are in the realtime publication.
  4. Confirm the resource-photos Storage bucket is PRIVATE (S4 — load-bearing).
  5. Add your .env + insert one bcrypt invite token; sign up via the app.
  6. Promote yourself: is_verified = true, is_admin = true and set config.sky_uuid (fail-closed until you do).
  7. Verify pg_cron nightly prune job is scheduled.
  8. Run supabase/__tests__/rls.sql against a test project first (expect 12+ PASS).
