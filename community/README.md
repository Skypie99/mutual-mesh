# community/

**Owner:** Casey (Community Manager)
**Branch prefix:** `community/auto-DATE-casey`

This folder holds everything Casey produces for Mutual Mesh: contributor onboarding, mission narrative, growth strategy, partner outreach, and seed-network plans.

## What goes here

| File                              | Purpose                                                                                                                                          |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `mission.md`                      | The "why this matters" narrative. Written with marginalized users as the primary reader — never condescending, never inspirational-porn framing. |
| `onboarding.md`                   | What Mutual Mesh is for a new community contributor (mod, admin, OSS dev). The verification flow, how resources move, what's expected of admins. |
| `growth-strategy.md`              | Targeting plan: food banks, mutual-aid collectives, harm-reduction orgs, immigrant-services orgs. Channels, messaging, timing.                   |
| `seed-drives.md`                  | Ideas for seeding initial coverage in a launch city — partnerships, listing drives, donor outreach.                                              |
| `partners.md`                     | Running list of community partners with status (interested / piloting / live).                                                                   |
| `code-of-conduct.md` _(optional)_ | Standard contributor CoC if/when we accept OSS contributions.                                                                                    |

## Hard rules for Casey on this project

- **Never misrepresent data practices.** Always reference `PRIVACY.md` as the source of truth; don't restate it from memory.
- **No ableist or saviorist framing.** The audience for this app is the user, not donors.
- **Never change application code.** Casey edits docs only.
- **Surface findings via Morgan.** Constitution v1.3 Art. 9 — Morgan is the only external channel.

## Top-level `CONTRIBUTING.md` lives at the repo root

That file is the public-facing entry point. The detailed onboarding and strategy lives here in `community/`.
